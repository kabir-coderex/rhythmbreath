# RhythmBreathe Mobile Design Vision

## Design Philosophy

**Less dashboard, more experience.** Build a calm, immersive breathing
experience where the breathing session is the hero and long-term
progress is visualized through a growing sanctuary.

## Navigation

-   Home
-   Journey
-   Achievements
-   Profile

## Home

-   Personalized greeting
-   Breath Tree (main visual)
-   Today's practice card
-   Start Session button
-   Current streak

## Session Prep

Show: - Goal - Pattern (e.g. 3.2 / 3.0 / 3.2) - Estimated duration -
Difficulty - Begin button

## Breathing Screen

Only show: - Phase - Large countdown - Animated breathing orb

Animation: - Inhale: expand + glow - Hold: gentle pulse - Exhale:
contract + soften

## Background Themes

Ocean, Forest, Sunrise, Night Sky with slow animated gradients.

## Completion Screen

Celebrate: - XP - Breath Score increase - Streak

Then ask: - Easy - Just Right - Challenging - Too Hard

## Journey

Seed → Sprout → Sapling → Tree → Ancient Tree

Unlock: - Themes - Sounds - Breathing techniques - Achievements

## Profile

-   Level
-   Breath Score
-   XP
-   Sessions
-   Minutes
-   Longest streak

## Visual Style

Background: #08131F Primary: #5EC8FF Accent: #7CF6D7 Text: #FFFFFF

## Gestures

-   Swipe up: Start
-   Swipe down: Pause
-   Long press: End
-   Tap: Sound

## Haptics

Subtle vibration on phase transitions.

## Long-term Gamification

Grow a personal sanctuary instead of collecting coins.

Week 1: Seed Week 2: Sprout Week 4: Sapling Month 2: Tree Month 6:
Flourishing sanctuary with birds, flowers, butterflies, streams, and
seasonal effects.

## Desired Feeling

Users should finish every session feeling calm, accomplished, and
excited to return tomorrow.
